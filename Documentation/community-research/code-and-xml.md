# Anno 1800 code and XML discussions

This page indexes reusable findings from `#1800-code` in Anno Mod-Corner International. The export covers 103,642 unique messages from 16 May 2019 through 24 November 2026 in 21 HTML files. The first pass searched the whole export by theme and time period, then read selected threads, linked sources and attachments. The messages cited below are traceable to the local export even when a Discord link requires server access. See the [review scope and release dates](README.md).

## ModOps and load order

| Topic | Finding and evidence |
| --- | --- |
| Late-phase typo | A July 2025 compatibility discussion traced a warehouse integration ordering issue to `"#"` used where the author intended `"*"`. The pinned 1800 sorter checks explicitly for `"*"` in the ordering dependencies. The public metadata spec defines ordering through `LoadAfterIds`. The older thread discussing a load-first mechanism was a design discussion. For a compatibility patch against a separately ordered submod, account for the ModID of the submod that creates the target. [2025 diagnosis](https://discord.com/channels/578443209940926465/578443576552325143/1399746149425872906), [author's correction](https://discord.com/channels/578443209940926465/578443576552325143/1399748572647264286), [submod example, 2026](https://discord.com/channels/578443209940926465/578443576552325143/1460962277199970305), [Modinfo specification](https://github.com/anno-mods/Modinfo/blob/master/modinfo-format.md#loadafterids-optional), [loader source](https://github.com/jakobharder/anno-mod-loader/blob/8326b7c5a7648787c52f1252cd6e8ae60e593d1c/libs/xml-operations/src/mod_loading_order.cc#L153), [loading guidance](../foundations/structure-and-loading.md#loading-order-and-nested-helpers). |
| Multiple ModID conditions | The September 2025 discussion distinguishes Anno 117 inline Boolean conditions from 1800 nested groups. The published reference marks the combined expression as 117 and provides the nested 1800 form. The active ModID check and the order in which its content arrives are separate checks. [Discord clarification](https://discord.com/channels/578443209940926465/578443576552325143/1417190866392580230), [reference](https://jakobharder.github.io/anno-mod-loader/modops/control/#modid-condition), [1800 ModOps](../xml/modops.md#modid-conditions). |
| Changes to a shared list | In a 2025 pirate trigger patch review, a merge of `TriggerActions` could change entries another mod placed in the list. Loader source confirms positional treatment of repeated same-name children. The author agreed to append new actions. This preserves existing entries at the loader layer. The trigger's execution and save-state behavior require their own audit. [Review](https://discord.com/channels/578443209940926465/578443576552325143/1363597711022227729), [author response](https://discord.com/channels/578443209940926465/578443576552325143/1363601349798924329), [merge guidance](../xml/modops.md#merge). |
| Copying data already present in XML | A June 2026 thread demonstrates using an existing shared mod as a reference for `Content`: resolve the destination and source separately, then use the 1800 tab of the loader reference. The questioner reported success with two Vanilla production chains. Use the local [dynamic content chapter](../xml/content-and-lists.md) for the actual syntax and limits. [Example discussion](https://discord.com/channels/578443209940926465/578443576552325143/1515445543667630080), [reported result](https://discord.com/channels/578443209940926465/578443576552325143/1515452801160056832), [reference](https://jakobharder.github.io/anno-mod-loader/modops/content/). |
| Loader file aliases | The historic loader-11 link mentioned in a 2025 island thread has moved off the current branch. The live 1800 reference documents a text `.lnk` file whose path names the alias and whose content names its target, with island duplication as an example. This source establishes the documented feature. Behavior for a particular island package or archive remains unverified here. [Discord link](https://discord.com/channels/578443209940926465/578443576552325143/1408573604177772584), [current reference](https://jakobharder.github.io/anno-mod-loader/file-structure/#link-files). |

April 2023 is an important boundary for threads about standalone DLL installation. Ubisoft confirmed the built-in loader in April and added the in-game mod browser in GU18 in August. The [loader history](../reference/loader-history-and-tests.md) records the separate historical components. [Ubisoft on the integrated loader](https://www.anno-union.com/union-update-news-patch-plans-and-a-community-spotlight/), [GU18 release notes](https://www.anno-union.com/updates/anno-1800-pc-game-update-18/).

## Asset schema, gameplay and save state

| Topic | Finding and evidence |
| --- | --- |
| Item allocation and socket allocation | **Vanilla data.** In the current extraction, `Item/Allocation` is a `Choice` and defaults to `RadiusBuilding`. `ItemContainer/SocketAllocation` is `Flags`. Both use the `ItemAllocation` dataset. Museum module asset 1010481 serializes `Culture;Museum` in its socket field. The old register link in the discussion returns 404. The active 1800 register lists the existing `Mod1`–`Mod20` allocation slots and their assignments. The discussion's shared allocation mod is a lead whose linked code could not be fetched in this pass. [Discussion, 2025](https://discord.com/channels/578443209940926465/578443576552325143/1349184286871261224), [current allocation registry](https://github.com/anno-mods/GuidRanges/blob/main/1800/enums.md#itemallocation), [shared allocation mod link](https://github.com/Qurila/shared-mods/tree/main/shared_combi_allocations_kurila), [schema guide](../foundations/vanilla-research.md#struct-vector-and-array-nesting). |
| WorkingConditions with two populations sharing a workforce | Serp's Noblesse Oblige test and subsequent correction are recorded with the native context inventory in [the trigger conditions chapter](../gameplay/trigger-conditions.md#workingconditions-with-modded-populations). This is an ownership and save-state case as well as a pool lookup case. The linked helper was inspected in the workspace. [Initial test, 2025](https://discord.com/channels/578443209940926465/578443576552325143/1390413298947592323), [pool limitation](https://discord.com/channels/578443209940926465/578443576552325143/1398751220214005913), [migration follow-up](https://discord.com/channels/578443209940926465/578443576552325143/1399337453533270026), [helper source link](https://github.com/Serpens66/Anno-1800-SharedMods-for-Modders-/tree/main/shared_WorkCondFix). |
| Fine-grained influence costs | **Published mod source.** The One Step Influence example pairs per-asset `Cost/InfluenceCostPoints` with the category-level `InfluenceConfig` on asset 140797. Its Townhall, GuildHouse and HarborOffice rules set a unit multiplier and account for the named Spice rebalance mod. It defines both a normal and a rebalance path with different free allowances. [Graphics question](https://discord.com/channels/578443209940926465/1080167315452203040/1345072752935047261), [Code response, 2025](https://discord.com/channels/578443209940926465/578443576552325143/1345075412170182730), [shared mod source](https://github.com/anno-mods/shared-resources/blob/554da1cf86b07004a23576443affa5c022c47fd2/%5BShared%5D%20One%20Step%20Influence/data/config/export/main/asset/assets.xml). |
| Ore slots that revert after a load | **Author report.** New World ore-deposit changes were reported to revert on save reload, linked to the `DLCSlotReplacements` block in slot asset 614. Removing the retrofit was discussed but can affect DLC activation on an existing save. The separate deposit mod's public listing is available. A current game/save reproduction and the scope across sessions and slot types remain pending. [2024 explanation](https://discord.com/channels/578443209940926465/578443576552325143/1236320818594582729), [2026 follow-up](https://discord.com/channels/578443209940926465/578443576552325143/1558838194018066548), [deposit mod](https://www.nexusmods.com/anno1800/mods/501). |

It offers possible starting points for tracing AI difficulty and explicitly leaves the actual effect open. [Graphics question](https://discord.com/channels/578443209940926465/1080167315452203040/1097796031137189940), [code discussion](https://discord.com/channels/578443209940926465/578443576552325143/1097840495851470970). |
| Ship status stages and targeting | **Author reports.** An August 2023 screenshot shows three fire status icons together for one gunboat in a flamethrower discussion. The screenshot establishes simultaneous icons in that scene. It leaves hit count and current behavior open. A separate May 2024 seamine experiment reported different automatic targeting for objects carrying `Bombarder` even after changing `MilitaryFeature/CanAttackTable`. The exact engine gate was unresolved. [Status-chain report and screenshot](https://discord.com/channels/578443209940926465/578443576552325143/1138203833563107369), [seamine report](https://discord.com/channels/578443209940926465/578443576552325143/1237560684900913243). |
| Increased ship HP | **Conflicting reports.** One July 2025 discussion cites roughly 32k HP as a possible limit and 23k as another author's reported load threshold. Neither value is established as a general bound. The author reports using `DamageReceiveFactor` as a different balancing mechanism. The saved value, display value and combat behavior still need independent checks. [Discussion](https://discord.com/channels/578443209940926465/578443576552325143/1390976868836048916). |

The discussion distinguishes attachment through that UI from a separately placed building with a range effect. The exact crash cause, component requirements and existing-save behavior remain open. The two linked Gists were inaccessible. ## Lua, UI and diagnostics

- **Selection and infotip discovery.** One discussion points to the textsource catalogue and distinguishes a selected object (`ts.Selection.Object.GUID`) from an object under the cursor (`ts.Selection.Picked.GUID`). It suggests tracing a visible tooltip through decoded infotip data to find the specific textsource expression. These are diagnostic leads. The returned object and script context need to be checked in the target feature. [Discord discussion](https://discord.com/channels/578443209940926465/578443576552325143/1403707582425726998), [community command catalogue](https://github.com/anno-mods/modding-guide/blob/main/Scripting/ts_commands.txt), [older game catalogue](https://github.com/anno-mods/modding-guide/blob/main/Scripting/textsourcelist.json), [infotip lookup](../ui-and-resources/infotips-and-text.md#find-the-layout-for-a-specific-ui-area).
- **Trigger registration and Coop.** A 2026 discussion gives a motivation for preferring a feature-unlock transition in some shared mods: direct Lua registration can duplicate execution when several peers share a participant. The author reports using `SetUnlockNet` and `SetRelockNet` to drive an XML condition. This is evidence of an author pattern. The exact repeat, save and Coop contract depends on the guard and trigger. [Discussion](https://discord.com/channels/578443209940926465/578443576552325143/1480264714020720722), [trigger lifecycle](../gameplay/triggers.md#registration-repeat-execution-and-initialization), [synchronization overview](../multiplayer/synchronization.md).
- **Session entry and a saved game's first visit.** A 2025 discussion distinguishes ordinary session entry from the helper mods `shared_EventOnGameLoaded` and `shared_OncePerSessionPerSaveLoad`. The latter is cited in a follow-up about `ActionBuff` and sessions loaded after the original action. These are author-reported behaviors. Audit exact helper revisions, event registration and repeat behavior before reusing them. [Reset discussion](https://discord.com/channels/578443209940926465/578443576552325143/1409139818423648387), [buff discussion](https://discord.com/channels/578443209940926465/578443576552325143/1423756703555649657).
- **Localization load versus glyph display.** Two July 2025 attachments were inspected. The first package contained an 8.5 MB replacement `TextExport` in `texts_russian.xml`; its author reported that it did not load as intended. The second contained a two-entry `ModOps` patch. A later screenshot shows an English test label and question marks in the other field. This confirms visible patch output and a separate unresolved glyph problem in that test. Both the file format and the size changed between packages, so the trial cannot isolate a file size limit. An earlier Vietnamese thread reports success after supplying translated text and matching font and blacklist files. Its exact main-menu and font behavior remains an author report. [First package](https://discord.com/channels/578443209940926465/578443576552325143/1395671830517256273), [second package](https://discord.com/channels/578443209940926465/578443576552325143/1395690618805817425), [screenshot](https://discord.com/channels/578443209940926465/578443576552325143/1395691161708003399), [Vietnamese follow-up](https://discord.com/channels/578443209940926465/578443576552325143/1198632284459372625).
- **Infotip examples for special output types.** In November 2026 Serp pointed to a `shared_TT_MenuInputOutputAmounts` patch for infotip 500683, including factories with abstract or buff outputs. The discussion includes a source excerpt. The pinned XML shows a new visibility branch based on the first static factory input and a check to exclude monuments, alongside the original `HasProduction` branch. This is evidence of the mod's implementation. The visibility operators and native consumers still require an audit. [Discussion](https://discord.com/channels/578443209940926465/578443576552325143/1570127465043464293), [cited source revision](https://github.com/Serpens66/Anno-1800-SharedMods-for-Modders-/blob/4b3663d9a4045a63b30a1e93b0af2e81cda8c84f/shared_TT_MenuInputOutputAmounts/data/infotips/export.bin.xml#L336-L388).
- **Log monitoring.** The Anno Mod Forge author describes VS Code tasks that follow the game's newest log and handle loader log truncation. The repository page was accessible. Script execution and the behavior of the announced version remain unverified. For the built-in loader's log and the difference between diagnostic layers, see the [official FAQ](https://www.anno-union.com/modding-in-anno-1800-faq/) and [offline checks](../reference/offline-validation.md). [Announcement, 2025](https://discord.com/channels/578443209940926465/578443576552325143/1410771171632353351), [tool repository](https://github.com/Jopo-JP/Anno-Mod-Forge).
