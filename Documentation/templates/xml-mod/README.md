# Empty XML mod template

Copy this folder to a unique configured work subfolder. Replace ModID, ModName, Description and Creator before use. Choose a stable author-specific identity; a folder rename does not change metadata identity.

The empty ModOps root changes nothing. Complete the feature audit before adding operations. No asset GUIDs or shared helpers are allocated by this template. Do not install/publish it unchanged as a finished mod.

In the created mod, replace this README with actual behavior, dependencies, evidence, validation results and concrete game-test steps. Separate game/save/MP observations.
